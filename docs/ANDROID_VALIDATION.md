## 保存与行为

原生通过AtomicFile保存，上限1MiB，严格UTF-8和基础结构检查，接受存档版本1—3。损坏文本保留原文并交网页恢复，不因解析失败自动创建存档覆盖。导入经游戏完整校验才提交；系统文件选择器取消不修改进度，导出快照可在Activity恢复后继续。

网页关键操作先持久化再演出；原生接口返回失败时撤回资源、奖励、保底和随机状态。前后台生命周期代码暂停战斗，恢复后处理离线基础产出。

125/125逻辑检查、32/32真实浏览器检查及两路线零抽卡合法通关均已通过。浏览器另复核商城、抽卡跳过和动画中刷新。详见其他验证记录；浏览器结果不能代替原生系统行为验证。

标准工程提供AGP8.7.3、Gradle8.9、Java17和API35构建路径；GitHub Actions生成独立debug APK，不使用个人发布签名。源码提交54af5f3的[GitHub工作流](https://github.com/Yi-Lings/wendao-lingqi/actions/runs/37447879649)已通过125项逻辑检查和标准Gradle debug构建，并上传debug APK。

## 仍需实体设备检查

当前环境无adb、Android设备或模拟器，因此以下不标为通过：

1. API26/33/35安装与离线启动，以及覆盖原个人发布包后的旧档迁移。
2. 系统文件选择器、返回手势、刘海/键盘布局、文件提供器取消和写入失败。
3. 前后台、强制结束、WebView进程恢复、写入中断和Activity重建。
4. 低内存设备持续30分钟的帧率、内存、图片加载与发热。

下载后的APK可用 `audit-apk.py` 再核对资源与版本。卸载或清除应用数据会删除进度，覆盖安装前建议先导出存档备份。

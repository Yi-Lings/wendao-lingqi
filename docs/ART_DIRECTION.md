# 美术命名与品级规范

品级色表示物品稀有度。凡品白、灵品绿、玄品蓝、地品紫、天品橙、道品红用于边框、品级文字和标记；它们不决定物品本体的颜色。红装是红色品级的道品装备，物体可以是青玉、白衣、黑铁、蓝雷或多种元素。

物体外观依次服从实际名称、材质、部位和元素。高品级通过工艺、细节、镶嵌、浮空构件、法纹、粒子和动画提高华丽程度，不通过给整件物品统一染品级色实现。风、雷、冰、木、火、山岩、魂与星阵的光效分别沿用自己的颜色。

## 材质与华丽程度

- **凡品**：粗糙且磨损的普通材料，灰铁/旧布/绳石，完全无魔法光晕；套装只以小布带/简纹区别，不把凡品做成宝冠铠甲。
- **灵品**：整洁精工普通钢铁/青铜/皮革/青布，小型镶件和克制单层细纹，无大法阵。
- **玄品**：优质银铁/灵木/灵玉与清晰细灵纹，局部柔光，保留材料真实颜色。
- **地品**：复杂工艺与嵌晶、双层法纹和少量粒子；带“紫玄/紫电”的名字有紫色局部材质，但不把离火扇/撼山锤等染紫。
- **天品**：天灵宝级华美材质和强元素效果，金银镶边与丰富雕纹；本体按名字/流派，不强制橙金。
- **道品**：道品最高工艺，复杂法阵、浮空构件、魂/雷/风/生命等局部特效；完全不以红色品质决定本体配色。

青锋偏钢银、青玉、玉白与风青；玄武偏玄铁、岩灰、古铜和深苔绿；雷霄偏银、靛蓝、紫蓝电光；离火套按每件名字分木火水土金；太虚偏墨黑、月银、魂紫和幽青；回春偏竹青、玉白与星蓝。

## 已发现的具体错配

- 雷霄武器凡品至玄品分别为铁枪、精铁长枪、引雷枪，必须有枪尖；地品至道品分别为紫电杖、九霄雷杖、雷霄杖，必须使用真正的法杖。原 v3-items 第一行第 3 格为尖刃长武器，不能继续作为道品雷霄杖。
- 离火道品六件有独立元素：四象扇多元素、离火衣火红、木灵冠翠绿、寒潮腕冰蓝、地脉履岩褐、五行佩五色。
- 凡品回春铁尺旧图为木板，玄武布帽旧图为铁盔，均需按名称修正。
- 低阶技能旧图存在伏岳掌/镇骨甲的掌盾错置、火莲为蓝水滴、幽火为月轮、回春术为药鼎；新图应直接表现掌击/护甲、火莲、魂火、治疗生命光。
- 地品装备名字含紫玄/紫电时可有紫色材质；撼山锤、离火扇、玄冥刃、玄星尺仍按自身名称配色。
- 丹药玄武定身丹、渡厄丹、太一复元丹不因道品变全红；金石丹不因地品变全紫；无垢明心丹、玉清丹不因天品变全橙金。
- 通用节点天意石阶、失衡阵眼、迷路采药人、封存书匣分别应表现石阶、破裂阵盘、背草药篓的人和书匣，避免金焰莲、单独鬼脸、货车、金币箱的泛用替代。

## 验收原则

- 对照上述矩阵核对名称、格位、部位、材质和元素；不能仅凭图片数量或边框色宣布外观正确。
- 道品的风、木、水、土、魂、星阵等图格必须出现各自适合的颜色，整张道品图集不能只有一种赤金色。
- 品级边框与本体光效分离，禁止对物体图层用 hue-rotate 等方式强制染成品质色。
- 检查凡品磨损粗布与铁器、灵品皮革与青铜、地品名字中的局部紫材质，以及雷法从枪到杖的形态变化。
- 原资源完整保留；新图以单独文件加入，既有映射只有在形态和名称匹配时保留。
- 检查 360/390 宽手机、桌面、道品独立抽卡动画与离线试玩，确保图集不串格、不拉伸，元素光效不遮住物体。

## 复现

安装 Playwright 到 `qa-tools`，准备 Chromium headless shell 和中文字体。浏览器与字体属于验证工具，不是游戏运行依赖。

```sh
python3 -m http.server 8787 --bind 127.0.0.1 --directory web
```

另一终端：

```sh
node tests/browser-v3.cjs
```

可设 `LINGQI_ROOT`、`LINGQI_URL`、`LINGQI_CHROMIUM` 指定项目、服务及浏览器。`LINGQI_FILTER=jade` 只复核商城与抽卡，不代替完整32项报告。截图会等待弹窗完全显示，避免把淡入第一帧当成最终画面。

浏览器验证不代表 Android 真机验证。系统文件选择器、WebView 生命周期、安装覆盖和设备性能仍需实体设备检查，见 [ANDROID_VALIDATION.md](ANDROID_VALIDATION.md)。

## 已处理的问题

- 共修费用文案与实际费用不一致：UI 改为读取目录/视图成本。
- 被动修为达到门槛后按钮仍保持禁用：每秒刷新条件并在自动晋级时重绘。
- 离线弹窗读取错误的秒数键：改为使用 `elapsedMs` 并显示真实奖励。
- 妖王图格被横向拉伸：按照原始 3 × 4 图集的方形格保持 1:1。
- 测试夹具刷新时重写存档：修正为首次无存档才注入，避免测试自身制造的恢复失败。
- 宗门测试使用低阶丹方和加入前计数：改为加入后实际炼制五炉当前阶丹药，按正式规则领取。

## 复现

先安装 Playwright 到 `qa-tools` 并安装 Chromium headless shell；本机验证使用精简中英资源，因临时磁盘配额未保留全部 Chromium 语言/GPU包，不属于产品依赖。

```sh
python3 -m http.server 8787 --bind 127.0.0.1 --directory web
```

另一终端：

```sh
node tests/browser-v3.cjs
```

可通过 `LINGQI_ROOT`、`LINGQI_URL`、`LINGQI_CHROMIUM` 指定项目、服务 URL 和浏览器路径。测试退出时关闭自己的浏览器与上下文；HTTP 服务由启动者结束。

浏览器通过不等于安卓真机通过。此报告不声明系统文件选择器、安卓 WebView 生命周期或实体设备性能已经在真机验证；这些属于 Android 验证记录。

# 灵契 V4.2：历世与道心

日期：2026-10-15。本轮将主分支上的 V3.1 可靠性增强、新设计的奇遇机制，与已经发布在 V4.1 预览标签中的飞升、闭关、剧情、命名美术、音效和生产玩法整合为统一版本。沿用 V3 存档结构，补充可校验的历世手札。

## 机制与玩法

调研了《鬼谷八荒》《觅长生》《了不起的修仙模拟器》的开发者商店介绍，以及《凡人修仙传》《仙逆》《一念永恒》的官方作品信息与目录。具体来源、访问边界和设计推导见 [调研记录](RESEARCH_V3_2.md)。事件、人物、文字和数值使用灵契自己的内容。

- **六域历世**：18 段原创事件，每段三种选择，共 54 种选择；按当前主修的境界三、五、八层逐段开放。第一段另需真实通关青岚灵圃。可以回旧地补完，但每段全角色只结算一次，奖励按事件自身阶位固定。
- **三条道心**：破障、护生、求真分别积累印记，当前主张提供对应的攻击/暴击、气血/防御或穿透/真元回复收益。保留全部选择，历练外免费切换，战斗、洞天、共修及闭关期间禁止改动。
- **代价与结果公开**：每次选择显示消耗、所得与印记，求真始终提供无资源消耗的选项。确认前可关闭，确认后把结果写入可重读的手札。
- **战前筹备**：直接读取实际配置的打断、净化、护盾、回复和可用丹药，提供调整入口，不用面板战力推测胜率。原有免费试阵继续可用。
- **实时成长目标**：按修为、当前路线、材料、已完成事件、闭关和仙界状态给出下一步。与 V4.1 的备丹、吐纳、护阵、问心及飞升流程衔接。

每枚印记在对应主张下提供的收益：破障为 0.4% 攻击、0.1 个百分点暴击；护生为 0.5% 气血、0.3% 防御；求真为 0.2 个百分点穿透、每秒 0.04 真元回复。遵守已有属性上限与整数取整，具体构筑仍需实际挑战验证。

## 界面与可靠性

保留 V4.1 的六页面、全屏战斗/剧情、分页目录、音画和 216 件命名装备。新增可切换六域的山海图、事件抉择卡、道心页和手札；桌面山海图采用三列事件，手机保持纵向阅读，图集按原单元等比例裁切。

推荐配装先预览实际整套战力、换装清单、套装与道品特效变化，再确认应用。装备目录保留分页并增加战力收益、品质、获取时间排序与对比；避免一次展开 300 件物品。批量分解先列出物品与实际可容纳的返还，物品或保护状态变化后旧预览失效。

保存状态常驻显示，设置支持重试。首次保存失败保留入口，已有有效档写入失败仍可查看和导出。关键操作继续先保存再展示，保留 V4.1 已保存结果在展示异常后不回滚的处理。弹窗与物品详情包含键盘焦点并在退出时恢复；战术暂停且画面未变化时停止重复修改战斗 DOM。

## 验证

- **359 / 359 项逻辑检查**：包含 V4.1 既有检查与本轮新增检查，覆盖两路线 120 个成长节点、54 种选择在两路线的结算、实际道心属性、重复领取、前置/导入保护、资源上限、原有剧情闭关飞升及装备、美术、生产机制。
- **139 / 139 项浏览器检查**：基础 32、可靠性 15、新玩法 13、装备构筑 22、生产与命名美术 32、剧情闭关 10、飞升 4、完整性 9、独立离线 HTML 2。包含真实新账号成长、页面与物品详情焦点、保存失败、展示故障、原生接口模拟、短屏/横屏和桌面检查。
- **Android 构建成功**：Java 17、Gradle 8.9、AGP 8.7.3、API 35；APK 的全部 **107 个 Web 资源逐字节匹配源码**，签名验证通过，无网络、账户或共享存储权限。
- **网页独立包通过检查**：64 份音画资源原字节内嵌；无服务器打开文件，可完成奇遇并刷新恢复手札，无外部网络请求。

机器记录、源文件散列和截图统一保存在 [validation/v42](validation/v42/summary.json)。故障注入产生的预期错误单独记录；普通场景没有未处理页面异常。中后期 UI 夹具不作为长期经济平衡证据。当前未进行 Android 实体设备安装、文件选择器或长时间性能验证。

# V4.3：丹火与往事

日期：2026-10-16 UTC。沿用 [修仙游戏与小说调研](RESEARCH_V3_2.md)，落实 [V4.1 方案 A](ITERATION_PLAN_V4_1.md#7-数据分支与回看底座)：先让承诺、真实行动与留下的经历一致，再扩展长篇行动链。保留 V4.2 历世、道心、配装，以及原有剧情、飞升、音画和生产玩法。

## 亲制记录与具体约定

新增有界的 `production`：18 配方分别记录 `batches`（亲炼炉数）与 `quantity`（实际成丹），六套六部位按 `set:slot` 记录实际打造件数。即时成丹与队列收丹在真实产出时记账；一炉控火实得两枚仍只记一炉，批量七炉则记七炉及实际数量。排队、控火中途、取消、购买/抽取、奖励和试玩预置都不抵亲制。

11 处剧情制作目标改用具名配方或套装部位：九处指定回春丹/清心散，两处指定回春套装佩饰。任意品质都可完成器物目标，导航默认选择凡品，避免误导去追求红装。第一卷守护与求证现在分别亲炼回春丹与清心散；制作历史的起点在接到本幕约定时记录，旧库存和接取前的制作不能直接交差。

丹炉卡片显示累计亲炼炉数与产量，打造界面显示当前身份的亲铸数；新增「丹器手记」。收丹结算明确本次炉数、实得数量和控火额外，先保存再展示。

## 旧档与事务

V3 存档结构保持兼容。没有制作记录的旧档补空记录，保留原总统计和库存，不反推未知配方/部位。

已接受的故事使用目标规则版本：缺少 `rulesVersion` 时按版本 1 继续，新接受的故事为版本 2。旧约定的指标、baseline、当前幕、已读位置、选择、完成及奖励均保留；新约定使用具名制作。已完成故事不会重开或重复发奖。未知规则版本、制作 ID、字段、负数、小数、越界计数及不可能的控火产量不能导入。

制作记录、材料、物品、随机流和剧情状态仍由现有事务一起提交。满库存或保存失败不留下虚假制作进度；已保存后的展示故障保持既有不回滚规则。

## 往事全文

六卷主线与 18 支线完成后都可分段阅读：相遇、现场线索、抉择回应、各幕归来和最终归来。界面保留当时选择，只提供已走分支；旧档没有留下抉择时，明确显示“旧记录未保留抉择”，允许带标记的分支文本查阅。

阅读游标只存在界面，不调用故事推进/结算动作，不改原选择，不加好感、胜场、制作或奖励。正文独立滚动，分段导航与退出按钮保持可见，支持键盘。窄屏和横屏均保留可读正文区域；档案入口显示完成卷数和全文重读用途。

## 炼体入静

按炼体、锻骨、凝血、通脉、金身、破虚的实际目标编写六段专属场景：石庭听骨、泉畔归血、雾阶通脉、赤炉立身、裂隙留步、长明立身。序言、调息、阵纹解释、问心和历史回答均按路线呈现。炼体不再在问心正文里结金丹、开灵婴或铺展神识。

保留既有突破丹、费用、试炼和阵纹正确次序，界面解释同一主药也适合炼体护脉。终境仍为破虚圆满，不增加空的新境界。修法原有正文继续使用，当前存储索引与旧仪式进度不变。

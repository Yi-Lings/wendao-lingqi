# V4.7「行有所向」

本轮先评审现有心流断点，再参考成熟游戏的目标、反馈、挑战选择设计，落实可回归验证的改进。详细发现与复现见 [心流评审](review/FLOW_REVIEW_V4_7.md)，来源事实和设计推断见 [研究记录](research/FLOW_GAME_REFERENCES_V4_7.md)。

## 实现

- `engine.journey` 按实际丹药、丹炉作业、已学丹方和费用提供主动成长入口，缺料说明具体差额。用户保留停修、自由历练与原有单次操作。
- `story-focus.js` 根据真实存档计算可行动的故事目标；主页和当前结算显示实际幕次、计数、剩余条件或归来入口。临时选择不新增故事规则与永久目标字段。
- `battle-guidance.js` 展示真实战报最多两条具体事件，并区分通用准备建议。可恢复的战报提供同参数筹备与试阵入口，参数每次重新检查。
- 挑战抽屉集中呈现选择、门槛、奖励，实时更新按钮。正式试炼预览与执行共用门槛。出战配置保存成功后返回原挑战设置；失败仍留在配装页并回滚。
- 塔战记录可选 `floor`，旧报告不推测塔层；新字段只接受塔报告的 1–60 整数。
- 同一事务继续负责奖励与保存。导航、预览、历史复盘、目标卡均不额外结算。

## 验证边界

新档对照使用真实初始库存与公共动作；二十分钟诊断是规则时钟模拟，动作耗时为零。后期 UI 状态使用明确披露的境界/资源/任务夹具。它们不能证明自然节奏、主观心流、Android 真机体验或长期经济平衡。

Android 版本 4.7 / code11。美术和音频沿用已核验的原资源，本轮聚焦目标与反馈。

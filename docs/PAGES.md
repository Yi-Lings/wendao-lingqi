# 页面职责与交互

| 页面 | 主要功能 | 详细操作 |
|---|---|---|
| 修行 | 修炼、主修路线、小层晋级、大境突破 | 突破试炼从此进入独立战斗 |
| 角色 | 六部位灵装、成套装备、流派推荐、已学功法、出战配置、预设 | 点图片选择，长按说明；当前部位配装、套装与推荐各有独立入口 |
| 历练 | 选秘境、宗门试炼、妖王、问道塔、洞天 | 查看奖励与难度后进入独立战斗或探索 |
| 洞府 | 炼丹、打造、材料、生产设施 | 页内标签切换；丹方分页，炼丹队列保留在顶部 |
| 仙缘 | 主线、宗门、同行者、支线 | 标签区分各功能，支线分页 |
| 天道 | 券与灵玉抽卡、定向、悟道、兑换、集市 | 红卡独立演出；可跳过，奖励先保存；集市双币补给 |

战斗进入单独全屏场景，隐藏普通导航、资源栏和修行背景；敌人、气血真元、图片神通、灵宝、丹药以及暂停/退出集中显示。暂停和退出使用真实战斗状态；退出确认前先保存暂停。战斗结算后弹出真实奖励界面，展示胜利、星级、首通与入库物资；返回后保留原页面位置。自动重战先暂停下一场并保存，再展示上场奖励，点「继续挑战」后恢复。历史查看只呈现已结算战报，不重复发奖。洞天中途收益明确标注暂存，通关或归途携出后才记为入账。洞天同样使用独立路线界面，遭遇战进入战斗，完成后回到探索。

妖王使用独立的大图舞台，放大既有插画，增加入场威压、雾气、光环、冲击圈及命中反馈。各级妖王继续使用原本对应图集位置。

扫荡、即时炼丹、炉队列收丹、打造、任务/委托领取、共修完成、主动回收/退款及洞天采获使用独立结算弹层，显示该次实际保存的产出、数量、控火加成和消耗；打造装备可长按查看 UID 对应的实际属性，丹药也可查看用途。背包满时明确显示奖励暂存，洞天途中产出明确标记尚未携出。保存失败不显示成功结算并撤回该次状态；关闭或返回不再发奖，恢复来源抽屉的选项、输入与滚动位置。此弹层复用已保存状态，战斗继续使用自己的战报结算。集市购买与自动生产保持连续操作和原有即时反馈。

集市分常规资源、灵玉玉藏、感应兑换三个标签。常规资源支持 1/5/10 批次，选择灵玉或天道尘支付；只扣选中的货币，购买数量与库存即时更新。商品价格由经济模块公开，余额不足或存档失败时不保留未完成的交易。

角色的部位装备先打开养成详情，点击「更换装备」直达当前部位。当前穿戴单列，背包候选只显示同部位、排除当前穿戴，每页六件；点击替换，长按或详情查看完整属性。更换继承部位强化，翻页与换装保留弹窗位置。

「成套装备」按青锋、玄武、雷霄、离火、太虚、回春六套展示两件与四件实际效果、当前激活件数、适配功法和背包中的成套方案。一键装套只使用已有且当前境界可用的装备，没有候选的部位保留当前穿戴。六部位方案默认展开；缺件仍显示该套独立图片，长按预览基础属性，点击查看获取途径。获取页分别给出定向打造的精确材料与缺口、所有对应流派妖王的真实开放条件、道品感应定向；凡品至天品无需蓝图，道品才要求永久蓝图与天命晶。已拥有但境界不可用、奖励暂存中的物品分别标记。

「推荐配装」提供综合推荐与六流派方案，分别查看功法神通、装备方案、提升目标。根据当前背包、已学功法与开放槽位，推荐装备、心法、神通释放顺序与秘术，可一次装配并保存；灵宝与丹药保留当前配置。功法图卡、长按详情和图鉴显示流派定位、用途标签及搭配理由。成长目标给出补齐套装、获取核心功法或提升养成的真实来源。推荐使用战力及机制启发式评估，具体敌人的最优解仍取决于战斗机制。

同页操作更新已有节点，保留滚动、输入焦点及已展开的详情。切换目录页和主页面时才回到对应内容起点。长按 450ms 打开说明，移动或滚动取消，不触发误装配；也可以用详情按钮、右键或键盘查看。

`audio.js` 管理音乐、效果与持久音量偏好；`selection.js` 管理图片选择、草稿和详情；`builds.js` 生成流派推荐与成长目标；`equipment-art.js` 与 `game-art.js` 管理物品图片映射，`art-identity.js` 与 `item-art.css` 分别表达品级框和按名称的元素光效。`equipment-sources.js` 提供真实获取规则预览；`rewards.js` 呈现战利品；`activity-rewards.js` 呈现生产/收获；`art-crops.js` 保存新图集的实测边界，`art-layout.js` 在独立窗口中完整等比例呈现；原场景按原生尺寸等比例裁片，地图、Boss、同道和装备不拉伸或串格。六套×六部位×六品质共216个图片位置互不复用；48 功法/神通、12 灵宝、18 丹药、36 功能图标各自对应名称造型。原有美术保留于合适的器物与原场景；道品是红色框，器物自身可为玉白、青绿、玄黑、冰蓝等颜色。完整名称/图位/美术方向见 `ART_ASSET_MANIFEST.json` 与 `ART_DIRECTION.md`。游戏规则、奖励与存档仍由既有引擎负责，演出不产生第二份奖励。

网页版 `?preview=1` 使用专门的预置试玩进度和独立存档键；正常入口继续使用正式存档。单文件离线试玩包含所有图片与音频，可直接打开，不需要安装 APK。试玩预置资源用于快速体验，不代表自然游玩的成长速度。

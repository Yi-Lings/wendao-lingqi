问道·灵契 V3.2 预览版：红尘历世与道心构筑。

新增六域 18 段原创奇遇、54 种选择与历世手札。破障、护生、求真三条道心按真实选择积累印记，当前主张进入战斗属性，历练外免费切换。事件公开消耗和奖励，逐段解锁，每段只结算一次，旧存档自动兼容。

新增打断、净化、护盾、回复的战前筹备检查。手机保留五入口，桌面采用人物侧栏与双栏修行页；调整场景高度并修复图集宽屏拉伸。保留 V3.1 的成长目标、配装预览、装备对比、分解预览和保存失败重试。

这是使用调试签名的独立预览包，包名 com.lingqi.game.preview，Android 8.0 起。可与 V3 正式包共存；原版导出 JSON 后在预览版导入。APK 与源码 ZIP 在本 Release 的 Assets 中，附 SHA-256 校验文件。源码、调研、测试和截图随提交保存，私钥、工具链和缓存不入库。

Android 真机安装、系统文件选择器和长时间运行尚未验证。具体检查数量、构建校验与说明见 docs/ITERATION_V3_2.md。

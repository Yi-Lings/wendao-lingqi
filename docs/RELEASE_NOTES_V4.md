# 问道·灵契 V4.0 飞升体验版

六章主线与十八条支线改为可保存的多幕场景：调查线索、立下抉择、完成真实活动、听到途中回应，再领取结算。前期加入三轮斗技扬名与三轮秘境夺魁。

大境突破先准备筑基丹等同境丹药与材料，进入独立闭关界面，调息、布阵、面对心魔，再实战渡劫。缺少材料时可直接查看丹方研究、炼丹和副本来源。

完成六境与终章后可开启天门、立道誓、备飞升材料并实际挑战。飞升后开放登仙、真仙、金仙各十层，以及仙界历练、仙元成长和三位仙界人物的来信。

新增七张原创场景/人物/怪物图集，以及仙界配乐《云门长明》和飞升音效；原36张 PNG、14个 MP3全部保留。怪物按物种对应插画，仙兽与妖王使用独立大图战斗舞台。修复红品抽卡特写中的实际物品图片缺失。

APK 最低 Android 8.0，包名 `com.lingqi.game.preview`，可与旧发布版并排安装。旧签名私钥在恢复环境中缺失，因此本包使用调试签名；旧版导出的 JSON 可在体验包导入。

设置提供人界配装试玩、天门飞升试玩和正式仙途，三个存档相互隔离。试玩准备了资源与进度，正式仙途从新角色开始。网页 ZIP 解压后打开 HTML，所有音画已内嵌；首次交互启用音乐。

已验证逻辑、浏览器交互、两路线完整真实行动、移动端布局、APK编译/签名/资源完整性及公开下载。没有 Android 设备或模拟器，真机 WebView、系统文件选择器与长时间运行仍待设备验证。游戏为离线单机，宗门和竞技对手是本地 NPC。

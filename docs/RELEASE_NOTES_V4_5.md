# 问道·灵契 V4.5 · 接脉留灯

第一卷与第三卷新增三张可玩的接脉护阵图：旋转阵石、观察灵息、接回关键阵口与退路，取得正式历练履历后主动验阵。错接可逆转修正，结果随存档保留，成功后有同行者回应及只读札记。

- 新档首页可直接走进山海剧情，原成长目标继续显示。
- 手机单列、桌面双区护阵桌，底部动作可达，支持键盘与文字状态反馈。
- 三张新场景画、八幅独立证据插画实际接入主线、护阵、求证和藏画阁；全部原美术与音频保留。
- V1/V2/V3 已接任务沿用原规则，保存失败撤回本次转动或验阵，章节奖励不重复领取。
- 保留 V4.4 的证据判断、V4.3 的亲制约定、24 篇全文重读、炼体专属闭关及原有全部离线玩法。

Android 体验包 4.5/code9，最低 Android 8.0，包名 `com.lingqi.game.preview`，沿用原体验签名；旧体验版可覆盖安装，跨正式包可先导出 JSON 再导入。离线网页 ZIP 解压后打开同名 HTML，首次交互后播放声音。源码 ZIP 包含工程、美术、音频、方案、资料来源、测试和构建脚本。

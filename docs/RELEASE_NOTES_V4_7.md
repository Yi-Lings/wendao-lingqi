# 问道·灵契 V4.7 · 行有所向

本轮围绕目标、行动反馈与失败后的调整，改善修行、剧情和挑战之间的衔接。参考 Hades、Slay the Spire、Stardew Valley 及 GameFlow 的资料与设计推导见 [心流参考记录](https://github.com/Yi-Lings/wendao-lingqi/blob/main/docs/research/FLOW_GAME_REFERENCES_V4_7.md)。

- 成长指引结合当前修为、已有丹药、配方、材料和丹炉队列，建议服丹、炼丹或接续已有炉次。缺少材料时给出缺口与可达来源。
- 剧情指引显示眼前约定的具体行动与实际进度；行动结算连接仍待完成的目标或归来对话。
- 战前随阶位、难度、塔层和试阵选择更新条件、收益预览与按钮可用状态，避免点击后才得知入口尚未开放。
- 战后直接展示已有战报中的机制记录和应对建议，并提供保留原参数的重新筹备入口；准备完成后由玩家亲自开始挑战。

这些改动以减少迷路、无效点击和重复选择为目的。自动化检查与规则时钟模拟不能代替真实玩家的心流体验，首次二十分钟自然游玩、长期经济节奏和 Android 真机体验仍需实测。

版本为 4.7 / versionCode 11；保留既有离线玩法与体验包身份。构建、测试和公开下载状态以本轮实际验收及 Release 附件为准。

本轮已通过 464 项逻辑和 245 项浏览器检查（含 11 项实际离线文件检查），224 张截图归档。两条 Android CI 成功，131 个打包资源与 141 项冻结输入匹配，体验签名与对齐通过。资料与边界见 [验收记录](https://github.com/Yi-Lings/wendao-lingqi/blob/main/docs/validation/v47/README.md)。

APK、离线网页 ZIP、完整源码 ZIP 及各自校验文件已公开，六项匿名下载和 1565 项源码散列核验通过。公开核验见 [交付证据](https://github.com/Yi-Lings/wendao-lingqi/blob/main/docs/validation/v47/public-release.json)。

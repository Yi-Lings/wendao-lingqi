# 《问道·灵契》剧情重设计

更新日期：2026-10-07（香港时间）。本文件描述实现中的剧情内容与交互约定；实际结算仍由引擎与存档控制，静态文本不能发奖。

玩家从一名没有师承的山野散修开始，先在雪夜救治村人，再亲自打过冲霄斗技三轮、云隐秘境三关。山门执事不再只看来历，先前轻视玩家的对手骆景行在实际败阵后认错，并成为仍愿争胜、也能共同护路的同辈。主角身份的变化通过真实胜绩、台下反应、登名印和奖励发生。原创故事围绕镇山钟、被倒接的汲灵回路、旧盟与莫无迁展开，保留原六章、十八支线、三位伙伴和奖励定义。

## 从阅读到行动

每段剧情走完以下过程：

1. 在独立剧情场景中逐句进入事件；主线每章有 7–8 句开场，先交代人物、现场和眼前压力。
2. 检查两处有意义的环境线索。点击位置能看到具体发现，而非得到空泛的「线索 +1」。药根朝向、封签编号、旧战痕、被切断的书线提供判断依据；目前线索是必读门槛，尚未改变分支任务或奖励。
3. 作出两个局势明确的决定之一。内部 ID 仍为 `protect` / `seek`，按钮文案按章变化；伙伴回应玩家实际打算做的事，不重复套用「尊重自由」。
4. 去真实玩法执行任务。战斗要赢、炼丹要完成、打造要出器；此前累积的胜利不能替代本阶段接取后的行动。退出、失败、免费试阵不能被当成剧情胜利。
5. 主线完成第一、第二段后，回到剧情看 5–6 句的场间反馈和事件转折，再取得下一段任务。后段任务也从新检查点开始计数。
6. 完成第三段与尾声后，按引擎要求确认领奖。原章的修行、加入宗门、妖王、问道塔等累计要求依然存在；支线仍保留原前置、境界与好感条件。

因此主线有 **18 个实际行动阶段**，同一章的两个决定各有不同的回应和尾声；十八支线各有一次接取后的真实行动。不是看见选项就直接完成，也不是把早先玩过一次的记录一键兑换成全部章节。

斗技与秘境可以从历练独立进入。比赛胜绩、首次奖赏与称号依据实际战斗记录；剧情里的承认与身份变化依据走完的三段任务。以前赢过赛事的存档仍需完成新剧情阶段，但首次掉落不可重复领取。

## 六章主线

### 第一章：荒山入道

雪烧不出暖意，孩子呼出的气也不再发白。钟片反而随灵息流失变烫，药根被吸向山上。沈青岚不是给玩家递一张任务表，而是带着烫伤和疑问同行。山门试武帖为之后的身份翻转埋下引子。

- 守护路线：先取救命药、净炉成丹，再赢山门初试。村人脱离危机，顾寒舟当场把「巡使随从」的记名改成玩家自己的名字。
- 求证路线：先带阵纹活株、炼净方对照，再赢初试取得持证查炉的入场资格。顾寒舟需按胜绩接收此前被挡在门外的证物。
- 两条路线实际任务：青岚灵圃 → 完成一炉炼丹 → `arena_0`。三息共振、炉灰与村人的需求接续到丹房疑云。

### 第二章：宗门立身

冲霄斗技场按出身排席。顾寒舟只认登记胜绩，骆景行将主角视为陪行散修，陆月衡与青岚各自提供能落实到应对的提醒。白发老修士旁观，关键时刻见证，而非直接赐胜。

- 守护路线：稳住自己的节奏，逐轮保留回复与真元。首轮后对手开始看招，复试后改口按真正对手来打，决胜后当众认错。
- 求证路线：看清蓄力与收招，因地调整而不是背出一串招名。首胜让人愿意读查验记录，终胜取得不会被出身替换的公开验炉旁席。
- 实际任务：韩岳初试 `arena_0` → 叶惊鸿复试 `arena_1` → 骆景行决胜 `arena_2`。
- 完成反馈：三枚胜印、斗技头名、顾寒舟公开记名、骆景行抱拳、长老开始看莫无迁的验炉签名。奖赏与首次登名由真实战斗结算控制。

### 第三章：古府疑云

云隐争魁并非只抢一面旗；首席才能取到未删的原档。发亮的近路引人入汲灵支阵，脚下普通刻痕反而指向真实入口。素衍把阵图与矿样编号带入秘境，月衡提醒还有被困的抄档人。

- 守护路线：先留归路与接人准备，再争古殿首席。原档融霜受损一角，活着出来的抄档人补上日期。
- 求证路线：连续核验改门纹与原档入口，保全改阵印痕及日期；冻伤者的恢复写入反馈，而非以完美证物掩去代价。
- 实际任务：许照的破雾阵 `secret_0` → 季凌川的灵泉夺印 `secret_1` → 骆景行守殿对决 `secret_2`。
- 骆景行在最终阶段真正与玩家对决。败后收剑、挡开殿门余光，把副图和原档权交还，保留日后再争的动机。
- 莫无迁封退阵口的日期早于所谓灵息不足。公开证据不只归胜者，玩家的「秘境第一」由三关胜绩发生。

### 第四章：劫火人间

私塾敲碗求救，钟心与城中门牌被树根绑在一起。玩家已是两场争魁的首席，却仍需要部署、实际打断根须和补药。顾寒舟开始等待玩家的安排，身份改变在行为中可见。

- 守护路线：树王 `boss_6` → 灵圃补药 → 双生影卫 `boss_7`。二十三名孩子平安，点名簿保住；钟心坐标因外圈烧毁不完整，需要重新测图。
- 求证路线：树王 `boss_6` → 影卫 `boss_7` → 应急净药。钟心与转运坐标保全，私塾屋顶和点名簿未能留住，人已撤出。
- 两条路线都救人也查证，但先后安排影响能留住的细节；不以惩罚玩家选择为目的虚构「选错全灭」。

### 第五章：天道裂隙

旧盟对守桥弟子说主角是得意误事的首席。献城炉把户数变成归零数字，月蚀阵把炉火伪装成城灯。莫无迁的「救百城」说辞与私库回流同时可见，不靠一句正义宣言揭穿。

- 守护路线：熔炉 `boss_8` → 月蚀 `boss_9` → 玄河守将 `boss_10`。先让献城数字停下，再公开真图，最后拆掉仍按私印封路的桥锁。
- 求证路线：月蚀 `boss_9` → 熔炉 `boss_8` → 玄河守将 `boss_10`。先让守桥人看见力量去向，再当众截断回流，证明不仅会提出质疑。
- 骆景行送来有新封签的药箱、接后路，不替主角打胜关键战。守桥弟子摘下印、顾执事带人护城，表现玩家获得的认可正在改变他人的行动。

### 第六章：自证大道

取钟片不是结尾按钮。莫无迁仍问下一次灾年由谁承担，玩家须实造或实采可获得的材料，再用公开办法抵挡第二次真实劫兽验证。山下传来的轮值表回应第一章的雪夜与后来的登名。

- 守护路线：天隙劫兽 `boss_11` → 实际打造一件装备 → 再战 `boss_11`。修复退阵口，先让合钟与护阵稳定；常驻监守通过轮班而非强取灵息进行。
- 求证路线：天隙劫兽 `boss_11` → 沉星矿洞取普通基材 → 再战 `boss_11`。拆总册，分阵有自己的退阵与减载；可获得材料使新阵无需私人秘印。
- 第二次劫兽不会重复首通奖赏，只代表新阶段的实际验证。之前首次取钟片的胜利不能提前计为第二场。
- 终场回到第一夜的药锅、原始丹典与普通矿石。守山、远游、教人三种归途继续可选，不由亲密关系锁定。

主线三至五章可能要求玩家提升境界后再接下一战。任务导航必须展示副本原有境界门槛和修炼办法，不将未解锁误写成可以立即挑战，也不直接替玩家提升境界。

## 数据与画面约定

静态内容在 `web/story-scenes.js`：Node 返回 `{ episodes }`，浏览器使用 `window.WendaoStoryScenes`。全部对象递归冻结，不依赖运行时 RNG，也不授予物品。

```js
{
  id: 'chapter_0', kind: 'chapter', chapter: 0,
  title: '荒山入道', subtitle: '雪夜青岚 · 荒山入道',
  location: '青岚山麓 · 雪夜药圃', stakes: '现场的压力',
  cast: ['qinglan'],
  art: { file: 'v3-chapter-atlas.png', cols: 3, rows: 2, col: 0, row: 0 },
  intro: [{ speaker: 'qinglan', text: '一句人物对白', expression: 1 }],
  clues: [{ id: 'warm_shard', label: '发烫的钟片', text: '实际发现', speaker: 'qinglan', x: 28, y: 64 }],
  choices: [{
    id: 'protect', label: '符合这一章局势的决定', reply: [/* 逐句回应 */],
    goal: {/* 与 goals[0] 相同的预览别名 */},
    goals: [
      { key: 'dungeonWins', id: 'resource_herb', count: 1,
        label: '通关青岚灵圃，取回药材',
        nav: { page: 'adventure', modal: 'dungeon', payload: { id: 'resource_herb' } } },
      {/* 第二阶段 */}, {/* 第三阶段 */}
    ],
    interludes: [[/* 首段后对白 */], [/* 次段后对白 */]]
  }],
  outro: { protect: [/* 此决定的尾声 */], seek: [/* 另一尾声 */] },
  summary: '能放进回顾的具体变化'
}
```

支线使用 `questId` 代替 `chapter`，选择仅含 `goal`，没有额外三段数组。`unlockRank` 为后期世界支线提供接取下限；原要求仍在引擎结算前检查。目标只使用能继续增长的 `dungeonWins`、`bossWins`、`crafted`、`forged`，不使用已满级就永久锁死的好感、已知功法数或塔层数作为「再完成一次」目标。

文字中的新 NPC 暂由旁白明确引用姓名与台词。已有三位伙伴用原肖像表达状态；不得把骆景行的台词配成青岚肖像。现有六章与十二地图图集复用于对应地点，线索点击坐标是界面锚点，文字不声称旧插画本身已经画出了新人物或新物件。

## 验收需要回答的问题

- 新存档能从第一句读起，检查两条线索后才决定；没有「直接领本章」的绕行入口。
- 旧存档的既有完成章节和奖励保留，未完成章节需要走新剧情；重读不重复奖励。
- 同一目标在第二个阶段出现时，必须再真实完成一次；旧胜利或上一阶段的多余数量不能预付未来剧情。
- 炼丹排队不算成丹，控火与普通成丹只在真实产出后推进；失败、撤回与存档写入失败不得留下完成反馈。
- 所有任务目标都能导航到真实功能，未解锁副本显示真实条件，材料不足可回到可玩获取入口。
- 斗技初试、复试、决胜与秘境三关各为独立实际对手；称号和一次性奖赏以真实战斗记录保存。
- 360 px 宽屏幕逐句展示，线索、分支与操作不会把内容拉成一页长文；重开剧情能恢复到当前阶段。
- 原有战斗奖励页、生产结算页继续存在，完成后再回剧情推进；不把战斗、剧情和配置挤进同一页。

本文件是内容与行为的验收依据，不替代实际测试报告。测试结果及试玩下载由仓库的验证文档与 handoff 记录。

## 飞升与仙界续篇

人界六章走完后，不以「你已飞升」的一句话替代新玩法。独立文本模块 `web/ascension-scenes.js` 共 128 句，Node 返回冻结的场景对象，浏览器使用 `window.WendaoAscensionScenes`。仙修是旧六境之外的独立修炼进度，不抹除人界装备、功法、道誓、战报和伙伴。

### 叩天门

镇山钟长明后，天门照出完整的人间道痕，接引册却起初只列仙族来历。玩家取得渡界资格的方法仍是实际准备与实际战斗，而非靠斗技称号直接跳过守关。

- `invitation`：10 句。天门开启、旧胜被「下界」印压住、执律玄律告知问试规矩，三位伙伴明确准备与回程。
- `vows`：三个选择，每个有说明与 5 句独立回应。
  - `protect`：继承守护，给后来者留可返回的天阶；青岚留山守路，素衍接坐标，月衡提醒向仙界医者求助。
  - `seek`：继承求真，仙籍与高处的记录也须接受核验；把旧档日期、具体受影响的人和原笔者带入新的调查方法。
  - `promise`：继承传道，留下可用的材料、失败与停阵记录；下一页仍需主角亲学，不因飞升就凭空全知。
- `condense`：8 句。材料、丹药与调息准备，顾寒舟承认昔日怠慢，骆景行留下下一次真实邀战；阵前明确材料将在正式开阵时实际消耗。
- `trial`：5 句可供战前演出。守关阵、退回线、三段雷息的应对，以及天门不凭门第赐胜。具体进入方式由飞升状态机决定。
- 必须完成 `heaven_gate` 对应真实守关战，才可读成功演出。退出、失败与试阵不授予飞升；材料与失败重试规则须以 UI 与引擎实际明细显示，文本不替代成本判断。
- `return`：守护道誓 9 句，其余每条 8 句。玄律按实绩补仙籍，灵息入新气海，三位伙伴给出各自回应，最后进入仍需逐层修炼的仙关。守护、求真、传道的后果写进不同的临别反馈，而非只换一个标签。

### 登仙：仙关验名

七句抵达事件中，接引台原本先看仙族引旗。玩家提出以自己未来的试阵胜绩取得修炼席，先完成十层仙元积蓄；天门实绩保留，但不能自动替代仙关试阵。六句战前事件给出仙元续航与前摇应对，真实挑战后七句记录修炼席与执事当场承认。角落的下界修士重新展开战帖，让主角赢来的规则变化影响到下一位玩家之外的人。

### 真仙：云霄争榜

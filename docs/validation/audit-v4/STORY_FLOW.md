# V4 叙事、任务与成长心流审计

审计日期：2026-10-07。范围：最终运行时 `story-scenes.js`、`story.js`、`data.js`、`story-screen.js`；`breakthrough-ritual.js`、`ritual-screen.js`；`ascension-scenes.js`、`ascension.js`、`ascension-screen.js`；`preview.js`、`app.js` 的来源与任务导航；需求研究、FIRST30、全流程与浏览器报告。本文区分源码证据、已有自动验证与尚未验证的真人体验。没有做真人时长研究，也没有以试玩注资存档证明自然经济。

## 结论与需求对齐

- **非点选即完成：符合主要要求。** 主线每卷三项接取后的真实行动，支线每条一项；每段在进入 mission 时记录 baseline，旧胜利不能直接抵新约定。调查、选择、读对白不发奖励，终局和飞升有实际战斗、材料消耗与一次性保存约束。
- **可以飞升：实现且有自然可达性证据。** 完成人界任一路六境十层修为圆满、终境道誓、六卷主线，再经来信、立誓、凝道付费、天门新胜利、归来对白及主动落定。登仙/真仙/金仙各十层确实改变战力，不只是显示名称。
- **王道修仙爽点：已有清晰骨架，但人物与任务错配削弱兑现。** 荒山散修→斗技首席→秘境第一→执事请命→天门按胜绩记名，有具名对手失败后服气的反馈。第二、三卷选择按钮仍沿用旧任务文字，第二卷复试把实际对手叶惊鸿说成骆景行；必须修正。
- **故事足够长：只能称一条可玩的中短篇骨架。** “六主线、十八支线”是篇章数量；单次主线一路约 5 千字符，不能算成双分支总量。仙界来信合计约 2.4 千字符，全部为可展开文字，尚无三条独立、多幕的仙界任务线。
- **材料指引：人界突破较完整，剧情剩余门槛指引较弱。** 闭关给出研究、成丹、阵材与材料总需求，有确定研究途径，没有“必须先过突破才能得突破丹”的死锁。当前故事行动已完成时，继续按钮仍写“前往当前目标”，实际会悄悄转去首个未完成累计条件；易造成玩家以为任务未计数。
- **一念逍遥式长线：已实现修为—境界—配方/装备—历练—突破—飞升的联系。** 药田种植、灵兽专精、本命器、法则领悟、真实多人宗门等仍是研究建议，不能因研究文档列出而称已实现。现有五设施的被动材料生产不等于完整药田布局系统。

## 心流与等待：能够证明什么

FIRST30 采用每句/每操作3秒、战斗按真实模拟耗时的非最优策略；不是真人阅读实验。首境纯静修80修为/分钟，累计8,400，完全不服丹、不作战、不升级设施时，三层3.25分钟、五层10.75分钟、七层26.5分钟、十层圆满约105分钟。新角色实际有聚气丹和材料；引导样本约6.05分钟完成首卷、8.77分钟斗技夺魁、30分钟八层，因此不能称“新手必须等待105分钟才有内容”。

真正的早期断点是：先赢完第二卷三轮，叙事承诺已兑现，却还不能听收尾，因为新玩家不知道四项隐藏累计目标怎么补。将当前已完成行动与剩余阶段目标分开，就能继续炼丹、山君、入宗、备筑基丹和资源挑战，维持可主动推进的选择。保持原门槛，不应直接发突破材料或削低条件遮蔽引导不足。

完整流程报告采用材料不足时 **168小时/7日粗采样**，另有24小时修炼推进。修法4200小时、炼体4368小时、159/157全胜只说明这套合法策略可达；报告已写 `waitHoursAreMinimum:false`。175/182日不是强制等待，也不是最快通关或真人日程。原2026-10-06的105日、115战V3报告已过时，V4结论应引用2026-10-07机器结果，并保留采样限制。

飞升后增长并不绑定真实等待时钟：静修是付费动作，猎场是真战，仙修可储备并逐层晋升。本轮应避免把“静修一周天”误解释成等一周；周天是一次凝炼动作。若UI宣传长线，以材料与实战成长描述，而不是虚构强制天数。

## 死锁、过早解锁与试玩边界

- 未发现正式人界突破丹的先试炼后研究死锁。18丹方可在适用境界确定研究；闭关说明明确不需先过当前试炼；实际消耗含丹方研究、成丹与阵材。重试保留已封存成本，不再扣第二次。
- 旧主线累计条件仍可由修炼/入宗/挑战完成，不是数学死门槛；世界支线有rank/previous门槛，须在界面显示，不应让“前往”看起来承诺可立即入场。
- 第五卷结尾要求 `boss_10` 终境三层，虽然卷自身要求第五境七层；原第六卷要求终境十层。该跨卷成长是合法长线，但应在第三幕前说明需要先跨境，免得地图突然锁住。
- 仙阶after的解锁是真实本阶试阵胜利，确有剧透控制；待修的是胜利后、实际凝定前的进阶语气，而非“未赢就显示胜利全文”。
- `createAscensionState` 明确直接供应终境、chapter=6、终境兼容记录及大量战力补偿；它用于天门交互测试，不能证实自然六境到天门。网页的正式/人界试玩/天门试玩三存档隔离已有浏览器证据。
- 结局选项是文本归途，teacher“开宗传道”不代表玩家真的获得建设宗门功能。人界story choices影响主线mercy/truth与好感；side choice留存于journeys和不同outro，但claimSidequest不改全局主线倾向、伙伴好感或后续玩法规则。应准确对外描述。

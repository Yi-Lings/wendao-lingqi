## 测试边界

首次进入与年龄勾选来自未注入的新账户。中后期装备、资源、终境和仙界状态为明确标记的有效夹具；终境夹具还含强化战斗属性以便稳定验证真实战斗、界面与保存结算。仪式与仙阶阶段通过引擎公开动作生成；章节缺条件测试明确使用任务记数夹具。加载之后均使用实际 DOM 操作，战斗通过真实引擎计时与结算。

本报告证明所测界面、操作、资源呈现和返回关系符合对应需求；它不单独证明完整养成经济、全流程平衡或真机音量表现。前两项由项目的零注入流程与经济验证覆盖；移动端系统安全区、实际触控和声音效果仍以真机体验为准。
